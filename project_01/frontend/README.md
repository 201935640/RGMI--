# 疾病相似性可视化系统

这是一个用于可视化疾病相似性网络和相关信息的交互式Web应用。

## 功能特点

- **疾病相似性网络可视化**: 以网络图的形式展示疾病之间的相似关系
- **疾病详细信息展示**: 显示疾病的基本信息、相关基因和miRNA等
- **实时疾病查询**: 通过后端API实时查询特定疾病的相似性信息
- **交互式操作**: 支持缩放、拖拽、调整阈值等操作
- **响应式设计**: 适配不同屏幕尺寸的设备

## 安装与运行

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm start
```

应用将在 http://localhost:3000 上运行。

### 构建生产版本

```bash
npm run build
```

## 与后端集成

本应用支持通过API与后端服务器集成，以实现实时疾病查询功能。默认配置连接到 http://localhost:5000 的后端API服务器。

## 使用说明

1. **浏览疾病相似性网络**:
   - 在网络中查看疾病节点和连接
   - 调整相似性阈值筛选显示的疾病
   - 搜索特定疾病

2. **查看疾病详细信息**:
   - 点击网络中的疾病节点查看详细信息
   - 查看疾病的基因、miRNA等关联信息

3. **实时查询疾病**:
   - 确保后端API服务器已启动
   - 使用疾病ID或从下拉列表中选择疾病
   - 点击查询按钮，等待结果显示
