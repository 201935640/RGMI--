第 1 章作品概述
疾病作为生命科学领域的核心命题，始终是人类文明发展进程中无法回避的挑战，更是全球科研工作者致力攻克的重大课题。在传统研究范式下，疾病机制的解析往往受制于海量复杂生物信息的解析瓶颈。值得关注的是，得益于高通量测序技术和公共数据库（如 NCBI MedGen）的快速发展，生物医学领域对疾病相似性研究的需求日益增加，基于疾病相似性研究的新型范式应运而生 —— 通过构建疾病网络图谱揭示不同病种间的分子关联特征。研究表明，具有相似表型的疾病通常在基因表达调控、代谢通路异常等分子层面存在显著共性特征。这种跨疾病的系统生物学研究不仅能够突破单一病种研究的局限性，更可构建多维度的疾病关联网络，为药物重定位、跨适应症疗法开发以及个性化诊疗方案制定提供创新性的研究框架。同时，深度学习因其强大的特征提取和非线性建模能力，在疾病相似性预测中展现出优异性能，如显著提升预测准确率和复杂网络关系的挖掘能力。而且，有关疾病相似性的工具多以研究导向，缺乏直观的界面和实时预测功能。基于此，我们开发了 “疾视”，这是一个基于多元数据融合的疾病相似性预测系统，旨在将前沿生物信息学研究转化为实用工具，助力精准医学。
“疾视” 系统是一个创新的医学信息平台，通过整合基因表达、miRNA 调控和疾病表型等多维生物数据，精准预测疾病相似性。一方面，它可以作为生物医学研究人员、生物信息领域科研人员的辅助研究平台，以大数据 + 高性能交互平台 + 人工智能算法（RGMI 框架）作为疾病关联分析的数字化工具，可帮助药企、实验室等在共病研究和药物重定位中更直观地理解疾病的分子和表型关联（如糖尿病与心血管疾病），更高效率地开展研究。另一方面，作为相关专业学生的实验教学平台，它通过交互式生物网络可视化帮助学生理解深度学习模型在生物信息领域的应用，更形象地掌握疾病相似性预测的机制，具有良好的教学意义，有助于促进精准医学与交叉学科的发展。其核心 RGMI 框架（已被 ISBRA 2025（CCF C 类国际会议）录用）通过简化的模型架构实现高效预测，具有显著的科研和应用价值。
第 2 章问题分析
2.1 问题来源
当前，全球疾病种类繁多且新疾病不断涌现，给医疗系统带来巨大挑战。根据世界卫生组织数据，全球已知的疾病超过 55,000 种，其中包括大量新发传染病和复杂慢性病。这些疾病的诊断常因症状重叠或表型复杂而困难，误诊率在某些领域高达 20%-30%。例如，肺癌早期症状（如咳嗽、疲劳）易与慢性阻塞性肺病混淆，导致诊断延误。罕见病诊疗尤为困难，全球约有 7,000 种罕见病，影响超过 4 亿人，但 80% 的罕见病缺乏有效诊断方法。
与此同时，药物开发面临周期长、成本高的困境。据美国药物研究与制造商协会（PhRMA）统计，一种新药从研发到上市平均需 10-15 年，成本超过 25 亿美元，且成功率仅约 10%。药物重定位被认为是降低成本的有效途径，但需要深入了解疾病间的分子关联。
于是我们想通过疾病相似性研究去分析疾病之间的深层次关联，从而助力对疾病之间共病机制的分析、罕见病的治疗，优化诊断并支持药物重定位的研究。然而，当前疾病相似性研究面临多重挑战：传统方法依赖专家知识或单一数据源（如基因或症状），覆盖面有限且主观性强；多元数据整合虽能丰富信息，但引入稀疏性、噪声和对高质量标注的依赖；复杂计算模型（如多模态深度学习）在数据不足时表现不佳，且计算成本高，难以在资源受限环境中应用。此外，现有工具多为研究导向，缺乏直观的界面和实时预测功能，限制了非专业用户的使用。
2.2 现有解决方案
2.2.1 数据角度分析
数据分析主要有以下三个角度：
（1）基于语义分析：利用基因本体（Gene Ontology，GO）术语的语义相似性，构建疾病关联网络，通过计算 GO 术语间的信息内容距离预测疾病相似性。例如，2007 年发表在 Bioinformatics 的研究提出了一种基于 GO 术语的语义相似性度量方法，通过综合考虑 GO 术语的图结构和语义贡献，提供了一种更为准确的语义相似性度量方式。
（2）基于表型分析：通过人类表型本体（Human Phenotype Ontology，HPO）计算疾病表型间的相似性，支持疾病诊断和关联预测。例如，2018 年发表在 Bioinformatics 的研究开发了一个在线工具，提供的 PhenoSim 方法通过模拟患者表型数据中的噪声，并使用一种新的路径约束信息内容（Information Content，IC）测量方法来计算相似性。
（3）基于分子分析：通过整合基因、miRNA 等分子数据，构建多视图疾病网络预测疾病相似性。例如，2024 年发表在 Bioinformatics 的研究提出了 DiSMVC 框架，通过多视图图协同学习，显著提高了疾病相似性预测的准确率。
2.2.2 模型算法分析
利用深度学习的两种模型算法：
（1）基于深度表示学习的模型：2021 年发表在 Bioinformatics 的研究利用 LINE（Large-scale Information Network Embedding）模型，通过基因网络重构生成疾病的低维嵌入表示，预测疾病相似性。LINE 算法通过优化节点间的二阶邻居关系，捕捉基因网络的拓扑结构，成功预测了多种疾病的潜在关联。该方法在处理大规模网络时计算效率高，但存在无法深入学习结点潜在关联的问题。
（2）基于对比学习的图卷积神经网络模型：2022 年发表在 Bioinformatics 的研究采用对比学习的图卷积神经网络（GCN）框架，结合基因网络和疾病本体结构，通过优化正负样本的特征表示预测疾病相似性。该方法使用 HumanNet 数据库与 GO 术语的数据，通过对比学习增强疾病节点间的区分能力，能较好的融合基因数据与 GO 数据，综合评价疾病相似性。
2.3 本作品要解决的痛点问题
（1）使用什么样的多元生物数据，怎样的生物数据可以更好的结合使预测结果更加全面，对于不同的生物数据，怎么针对性地选择不同的模型进行处理，怎样调节不同生物数据在预测疾病相似性作用的重要性，如何尽可能地减少不同生物数据引入的噪声。
（2）如何构建高效、鲁棒的疾病相似性预测模型，如何处理现有疾病相似性预测模型在处理大规模、多模态生物数据时面临计算复杂度高、标注数据依赖强、泛化能力有限的问题。如何提升模型对稀疏数据的泛化能力，如何降低计算开销，同时保持高准确率？
（3）如何优化平台的用户体验以满足多样化需求：现有疾病相似性工具多为研究导向，缺乏直观的界面和实时预测功能，难以被非专业用户使用。如何设计简洁、直观、响应式的界面，实现灵活的数据查询和交互式可视化工具，使用户能轻松访问和分析疾病相似性数据？如何通过用户权限管理和定制化配置满足不同用户群体的特殊需求，提供简洁、易用的操作体验，增强平台的用户黏性和科研价值？
2.4 解决问题的思路
（1）数据整合与特征提取：采用基于分子的方法研究，既从遗传和转录的角度考虑潜在的分子机制，同时又利用有价值的先验疾病关联知识以监督的方式结合表型可解释的多发病来捕捉具体关联模式。整合 HumanNet、RNADisease 和 DisGeNET 等多元生物数据库，根据不同数据的特色，分别采用不同的深度学习模型针对性地处理，从而捕捉多元数据之间的复杂交互模式。
（2）模型优化：采用更加先进的深度学习模型，并且引入轻量化架构降低计算复杂度，同时实现高准确率。通过双线性变换捕捉特征间的复杂交互生成预测分数，并且考虑基于 ReconBoost 的模态融合策略，交替优化基因和 miRNA 模态，并且融合疾病表征，通过动态加权和正则化增强模型鲁棒性。
（3）平台优化：优化平台界面，提升用户体验和易用性，使用户能够快速获取疾病相似性信息。具体措施包括精简界面元素，采用 React 和 Ant Design 开发响应式双语界面，提高交互性和可视化效果；提供友好的搜索和筛选功能，支持交互式可视化工具（如力导向图、雷达图）。通过 Flask API 实现快速数据查询。基于 HumanNet、RNADisease 和 DisGeNET 数据库，提供丰富的生物信息支持，满足研究人员、学生和临床医生的需求，增强平台科研价值。
第 3 章技术方案
3.1 RGMI 预测框架
RGMI，一种预测疾病相似性的方法，包含四个模块：（I）多模态特征编码，（II）动态嵌入加权，（III）双线性得分预测，（IV）迭代模态融合。这些组件协同工作以提取特征、增强表示、生成相似性得分并确保多模态一致性，从而实现准确预测。
3.1.1 多模态特征编码
我们首先构建了一个多模态异构网络，整合了基因和 miRNA 两种数据源。基因数据通过图结构表示为 G_g=(V_g, E_g)，其中是 V_g 基因节点集，E_g 是基于基因共表达或功能关联的边集。类似地，miRNA 数据表示为 G_m=(V_m, E_m)，其中 V_m 是 miRNA 节点集，E_m 反映 miRNA 之间的相似性或调控关系。为了将疾病与这些分子数据关联，我们引入了疾病 - 基因关联矩阵 D2G 和疾病 - miRNA 关联矩阵 M2D，分别记录疾病与基因和 miRNA 之间的已知关系，从而形成一个统一的异构网络。利用该网络，我们采用神经网络从图结构中提取特征。
对于基因相互作用网络 G_g，构建了带有 GCN 的图编码器。GCN 利用网络上的卷积运算和消息传递机制，通过考虑局部和全局邻域结构来学习和更新节点嵌入。
对于 miRNA 相似性网络 Gm，为了减少其中的噪声干扰，使用了改进的图注意力网络 GATv2 来提取 miRNA 特征。与 GCN 不同，GATv2 通过聚合具有不同关注系数的邻域信息来提取节点特征，而相比于 GAT，GATv2 优化了注意力机制。
3.1.2 动态嵌入加权
并非所有基因或 miRNA 对疾病相似性预测的贡献相同，因此我们设计了一种动态加权机制，以增强模型对重要特征的关注。在动态嵌入加权模块中，我们采用了多层感知器（MLP）技术，通过线性变换和 ReLU 激活函数提取节点特征，并利用 sigmoid 函数将输出归一化到 [0, 1] 区间，以量化每个基因或 miRNA 节点的重要性。结合加权聚合公式，该机制实现了对节点嵌入的动态加权，增强了模型对关键分子特征的关注，从而提升疾病相似性预测的准确性。
3.1.3 双线性得分预测
在获得疾病的多模态嵌入后，受到视觉识别中双线性变换的启发，我们设计了一个轻量级的双线性塔模型来预测疾病对之间的相似性得分。对于每一对疾病，我们从嵌入矩阵中提取对应的嵌入，构建特征向量。相较于普通的拼接方式，这些向量能够更好地捕捉疾病对之间的相似性和差异性，并且在小规模数据集上能更有效地利用数据。特征向量分别输入到基因塔和 miRNA 塔中。每个塔首先通过线性投影将输入维度降到隐藏维度，然后使用双线性操作计算得分。
3.1.4 迭代模态融合
为了充分利用多模态信息并避免单一模态主导预测，受到 ReconBoost 的启发（一种通过历史预测增强多模态一致性的正则化策略），我们采用了一种交替训练策略来优化模态融合。在每一轮训练中，我们选择一种模态（如基因或 miRNA）更新参数，同时保持其他模态固定。更新目标通过一个动态损失函数实现。并且为了优化可学习参数，我们在训练过程中使用 Adam 优化器更新模型，确保模型有效收敛并为下游任务生成准确的得分。
3.2 疾视平台
疾视 - 基于分子交互作用的在线式疾病相似性可视化平台，旨为了满足新药研发以及药物重定位的需求而推出的基于深度学习 RGMI 模型的开发平台。平台主要分为三个模块：疾病 - 基因关联预测模块、分子网络 - 相似性信息模块、用户管理模块。本项目是一个基于深度学习框架的 Web 端平台，以 RGMI 模型为主体，实现数据挖掘，可视化，信息检索功能，下面主要介绍数据处理与平台设计。
（1）疾病相似性网络可视化模块：该模块基于现代 Web 技术架构，利用 React 框架结合 D3.js、Three.js 等可视化库，实现了疾病之间相似性的多维度展示。在数据处理方面，系统对从 RGMI 模型获取的疾病相似性数据进行了预处理，包括数据清洗、格式转换、特征提取等步骤。通过力导向图、环形图等多种可视化方式，将疾病间的复杂关系直观呈现。系统支持交互式操作，用户可通过拖拽、缩放、旋转网络图，探索疾病之间的潜在联系，同时提供相似度阈值调整功能，使用户能根据需求筛选显示不同强度的疾病关联。后续在可视化效果优化方面，考虑增加更多的交互功能，会引入 3D 网络图和 VR 视角，利用 WebGL 技术提升大规模疾病网络的渲染性能，实现数据分层加载机制，优先显示核心疾病节点，其他节点按需加载，以提高用户体验。此外，平台提供强大的搜索和筛选功能，支持疾病名称模糊搜索、基于症状分类浏览，对所涉及的多个疾病数据进行聚类分析和结果优化，帮助用户从海量疾病关联数据中快速找到有用的信息和规律。后续在结果可视化处理方面，将增加图像处理技术，如疾病网络的社区检测、中心性分析，提取网络中的关键节点和模块，进行网络结构分析，帮助用户理解疾病的聚类特征和关键疾病节点，为药物靶点发现提供参考。
（2）疾病 - 基因 - miRNA 关联信息模块：利用 HumanNet、DisGeNET、RNAdisease、ENCORI 数据库获取原始数据。在疾病详情页面中，通过输入 Disease ID 或疾病名称，系统利用后端 Flask 框架处理请求，通过数据挖掘和分析技术，展示疾病的详细信息、相关基因列表、相似疾病推荐以及相关学术文献链接。该模块采用组件化设计，实现了高效的数据展示和用户交互。
（3）用户管理模块：实现了用户的登录、注册以及个人信息展示。平台采用前后端分离架构，前端使用 Ant Design 组件库构建统一美观的界面，后端采用 RESTful API 设计规范。安全方面，系统使用 OpenID 协议验证用户身份，RBAC（基于角色的访问控制）控制用户权限，SSL/TLS 协议加密传输敏感数据，并在用户注册后将个人信息安全存储到数据库，最后利用响应式设计技术确保平台在不同设备上的良好适配。后续将优化用户体验，实现用户浏览历史和收藏功能的一体化管理；增强系统安全性，引入防火墙和数据加密技术保护用户信息；同时加入用户反馈机制，提供在线智能客服、用户调查问卷等功能收集用户需求，持续优化平台功能和性能。
第 4 章系统实现

4.2 后端设计
本项目后端部分基于 Django 框架进行开发，使用了多个 Python 库来支持项目的功能集成。其中，利用了 PyNetworkx 提供的用于处理复杂网络和图结构的 API，并使用了一系列用于解析、处理和可视化网络数据的工具；利用 Flask 用于在 Python 环境中搭建和启动化 RESTful API 的操作；通过 Pandas 访问多种结构化数据源，来控制相关数据。此外，还利用了 D3.js 这个用于创建模和化学信息学的 Python 库，通过 D3.js 使得可以处理用户输入的疾病名称序列等。
本项目的数据库部分基于 MySQL 数据库进行构建，设有用户信息管理的数据库以及前端图像展示的疾病及相似性分值的 URL 链接数据库。用户信息管理的数据库目的在于对项目使用群体的注册信息进行保存和更新，方便用户使用搜索历史、预测结果等功能。利于开发者基于用户群体信息对各模块功能进行更新、优化、迭代。前端图像展示的疾病及其相似性分值的 URL 链接数据库，本项目前端展示的可视化图像其中疾病节点通过其相似性网络由 D3.js 绘制，其中节点之间的连接由相似度决定。并将本地绘制的图像送至服务器生成链接提供给前端进行展示。为了避免重复绘制图像，加快图像加载速度，本项目以此构建出 URL 链接数据库，对绘制过的图像 URL 进行保存。二次访问搜索时可以直接查询数据库进行访问，优化用户体验，降低服务器访问压力。
4.2.1 系统部署方法
在完成系统开发后，我们需要将部署到服务器上，以供用户访问和使用。我们可以选择云服务器进行部署。云服务器为阿里云 ecs.g6.large.1，操作系统为 CentOS 7.9 64 位，后利用宝塔 linux 面板作为服务器管理工具对服务器进行管理。而后在阿里云控制台上对服务器进行配置。在申请了域名后在服务器平台上添加了域名，将域名指向服务器的 IP 地址，最后上传网站文件和数据，将网站部署到服务器上，测试和调试网站，确保正常运行。
总体而言，我们面临了一些挑战，例如在疾病相似性网络的可视化表现上，尤其是当疾病节点数量达到几百个时，前端渲染性能会明显下降。为了解决这个问题，我们采取了数据分层加载机制，优先显示相似度较高的核心疾病节点，其他节点按需加载；同时优化了力导向算法参数，在保持网络布局可读性的同时减少计算量。这些优化使得系统能够流畅处理包含数百个节点的疾病网络。
在用户体验方面，我们通过多轮用户测试不断改进界面设计和交互流程。针对初学者，我们设计了交互式引导教程，采用 “边用边学” 的方式降低学习成本；对于专业用户，则提供了丰富的高级功能和自定义选项。这种渐进式设计既满足了初学者的易用性需求，又保证了专业用户对高级功能的可达性。
最终，我们成功构建了一个功能完整、交互流畅的疾病相似性可视化平台，为研究人员提供了探索疾病关联网络的有力工具，也为药物重定位和新药研发提供了数据支持。未来我们将继续优化系统性能，丰富可视化方式，并探索更多疾病数据的整合方法，进一步提升平台的实用价值。

第 6 章作品总结
6.1 作品特色与创新点
（1）多元数据整合与可视化：利用大数据技术，整合 HumanNet、RNADisease 和 DisGeNET 等生物数据库，获取基因、miRNA 和疾病关联数据，实现数据的全面性和多样性。进行数据预处理，对不同的数据采用针对的模型处理，确保数据可靠性与一致性。采用交互式可视化技术，通过 D3.js 和 ECharts 渲染力导向图和雷达图，直观展示疾病相似性网络和特征分布，帮助用户快速理解复杂分子关联，提高研究效率。
（2）集成预测与可视化功能：在疾病相似性预测基础上，集成了交互式网络可视化和用户管理功能，用户可通过响应式双语界面（基于 React 和 Ant Design）查看疾病关联网络、分析分子和表型共性，支持共病机制探索（如糖尿病与心血管疾病）与药物重定位研究。
（3）高效深度学习框架：基于 RGMI 框架，通过动态加权和模态融合策略，自动提取基因和 miRNA 的非线性特征，减少人工干预。模型训练后 AUROC 达 0.9658，显著优于基线模型（如 CoGO、DiSMVC），提供高准确率和鲁棒的疾病相似性预测。
6.2 应用推广
（1）提升疾病关联研究效率：平台帮助研究人员深入了解疾病间的分子和表型关联（如癌症与神经退行性疾病的共享路径），提高共病研究和药物重定位效率。生物医学研究人员可通过平台浏览多元数据，基于 RGMI 模型进行实时预测，探索新的疾病关联和治疗靶点。
（2）支持生物信息学验证：平台为生物信息学研究人员提供实时疾病相似性预测和交互式可视化结果，助力验证科学假设（如基因 - 疾病交互机制）。研究人员可利用力导向图分析疾病网络拓扑，结合 DisGeNET 数据深入研究疾病机制。
（3）教学与实验平台：作为生物信息学教学工具，平台为学生提供交互式学习环境，通过可视化疾病网络和预测实验，帮助学生理解疾病相似性预测原理和深度学习应用。学生可输入疾病 ID 进行模拟分析，掌握共病机制和分子交互知识。
推广方式：
宣传与营销：通过学术会议、期刊和社交媒体宣传平台功能，扩大平台的知名度和影响力，吸引对此领域有兴趣的用户。举办线上研讨会和推广活动，吸引高校、药企和研究机构用户。
合作伙伴关系：与药企、生物实验室和医院建立合作，提供定制化预测服务（如针对特定罕见病的分析），获取数据反馈以优化数据库和模型，提升平台影响力。
用户反馈：建立反馈机制，通过平台设置反馈页面，收集用户对界面、预测准确性和可视化的建议。定期举办用户交流会，通过邮件和社区论坛与用户互动，根据用户建议不断改进功能从而提高用户满意度。
6.3 作品展望
（1）技术升级：引入更多深度学习模型，增加更多可用的生物大数据，优化 RGMI 框架，进一步提升预测准确率。增加功能，如文献检索和 3D 疾病网络可视化，丰富用户分析体验。
（2）应用拓展：在疾病相似性预测基础上，扩展至疾病 - 药物交互（DDI）预测，增加蛋白质交互数据分析功能，应用于医学诊断、药物开发和公共卫生研究，帮助用户深入理解疾病机制和治疗策略。
（3）商业化发展：与药企和生物技术公司合作，提供基于疾病相似性的药物重定位服务，加速新药研发。接入高校资源，作为教学平台为学生提供实验工具，促进生物信息学教育普及。
（4）社会价值：将平台应用于公共卫生领域，助力医生和研究人员分析疾病共病机制，开发非专业用户模式，降低使用门槛，普及生物信息学知识，为全球健康事业贡献力量。
